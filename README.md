One short funny line for the One-Liner Laugh Lab bounty: the excuse a robot vacuum gives after eating a sock.

**Line:** "It's wrapped around my brush and won't come off. We're engaged."

The vacuum never denies eating the sock — it reports the jam exactly as it really happens, then deadpans into a wedding announcement, so the excuse is the mechanical truth and the punch is the commitment.

## Run it

```bash
python3 main.py
```

Writes the line to `/output/entry.txt`. Deterministic, offline, no trailing newline, 63 characters.
